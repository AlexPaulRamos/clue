*********RUNNING THE GAME*************
pygame, and numpy are required to be installed.
Run the main.py to play the game.
**************************************

**********How to Play****************
Arrow keys to move
H to view hand
Game set up and suggestion input is in the console
Turn information is at the top of the game window
***************************************

***********Navigation*****************
main.py is the main game file
clue folder holds all the classes
***************************************

**************IMPORTANT***********
Game window will stop responding while waiting console input.
CLOSING GAME WINDOW WILL END GAME
Game window will become responsive once console input is complete
*********************************
